# Transformation Studios website

Marketing site for the Transformation Studios app (iPhone, iPad and Mac): video, audio, photo, teleprompter, captions and transcripts in one studio.

- Everything published is in `site/`: `index.html`, plus CSS, JS, images and fonts under `site/assets/`.
- Images are real app screenshots; fonts are the app's own Fraunces and DM Sans.
- Hosted on Netlify: every push to `main` deploys.
- Next steps for production are in `CLAUDE-CODE-PROMPT.md`.
